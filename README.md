## 📖 О проекте

MineHub — pet-проект, разрабатываемый для изучения современной backend-разработки на платформе .NET.

Основная цель проекта — создание масштабируемой backend-системы для управления игровым сервером Minecraft с использованием принципов Domain-Driven Design (DDD) и Clean Architecture.
